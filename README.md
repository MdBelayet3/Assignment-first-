# New Year Celebration Website

This is a responsive New Year celebration landing page created using HTML and CSS. The project showcases a festive design with multiple sections like banner, offers, party details, portfolio, and newsletter subscription.


##  Project Overview

This project is a static website designed to celebrate the New Year. It includes visually appealing sections such as:

- Banner with New Year greeting  
- Discount offer section  
- Party invitation section  
- Event details (place, date, time)  
- Portfolio/product showcase  
- Newsletter subscription  
- Footer with contact and social links  


##  Project Purpose

This project was built as part of my learning journey in web development. Through this project, I practiced:

- Structuring a full webpage using HTML  
- Styling layouts using CSS  
- Using Google Fonts for better typography  
- Creating multiple sections like real-world landing pages  
- Organizing assets like images and styles

## Live Website

https://newyearcelebration2025.netlify.app/



##  Technologies Used

- HTML5  
- CSS3  
- Google Fonts (Merriweather, Inter)  


## Features

-  Attractive New Year-themed design  
-  Responsive layout (basic)  
-  Multiple sections (banner, offer, party, portfolio, etc.)  
-  Image-based UI design  
-  Newsletter subscription input field  
-  Footer with social media icons
